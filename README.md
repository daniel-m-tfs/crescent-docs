# 🌙 Crescent Framework - Documentation

Official documentation website for Crescent Framework.

**Live Site:** https://crescent.tyne.com.br

## 📁 Structure

```
site/
├── index.html       # Homepage
├── docs.html        # Documentation
├── styles.css       # Global styles
├── docs.css         # Docs styles
├── sitemap.xml      # Sitemap
└── robots.txt       # SEO
```

## 🚀 Development

Just open `index.html` in a browser or use a local server:

```bash
# Python
python3 -m http.server 8000

# Node.js
npx http-server

# PHP
php -S localhost:8000
```

## 🎨 Features

- Netflix-style hero with animations
- Fully responsive design
- Mobile hamburger menu
- Syntax highlighting with Prism.js
- SEO optimized
- Open Graph meta tags

## 📝 Content

To update documentation, edit `docs.html`.
